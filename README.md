# 三國演義・閱讀試煉

《三國演義》逐回閱讀檢測網站，以 Google Apps Script 綁定 Google 試算表執行。南山高中國文科製作。

## 功能

- **逐回閱讀**：每回附原文（可切換直排／橫排、調字級），詩詞與表文另以版面區隔。
- **每回五題**：以劇情理解為主，穿插人物、意象、修辭；交卷後顯示解析，並可跳回原文對應段落。
- **AI 插圖**：每回最精彩處附插圖（Gemini 生成，明代小說木刻插畫風格）。
- **古琴音樂與音效**：瀏覽器即時合成，無外部音檔。
- **學生存檔**：作答自動存檔，記錄閱讀位置；可設定是否允許重作（記首次、最高、最近得分）。
- **登入**：名單內學生用帳號密碼登入（首次登入以姓名驗證後自設密碼），名單外讀者可自行註冊。
- **教師後台**：依班級檢視成績總表、各題答對率與選項分布，可下載 Excel（班級總表、作答明細、各題答對率）。

## 檔案

| 檔案 | Apps Script 類型 | 說明 |
|---|---|---|
| `Code.gs` | 指令碼 | 伺服器端程式 |
| `Seed.gs` | 指令碼 | 第 1～5 回原文、題庫、插圖資料（初始化時寫入試算表） |
| `Index.html` | HTML | 網頁介面 |
| `img_1_1.html`～`img_5_2.html` | HTML | 內嵌插圖（JPEG base64） |

## 部署

1. 新增 Google 試算表 →「擴充功能 → Apps Script」。
2. 依上表建立 9 個檔案並貼上內容（HTML 檔名不要打 `.html`）。
3. 在編輯器執行 `setupSheets` 並授權，會建立「設定、學生名單、原文、題庫、插圖、存檔、作答紀錄」七個工作表。
4. 在「學生名單」填入學生，在「設定」修改「教師密碼」（預設 `nanshan`）。
5. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分「我」，存取權依需要選擇。

增加回數：直接在「原文」「題庫」「插圖」工作表新增列，再用試算表選單「三國演義閱讀檢測 → 清除網站快取」。

# 三國演義・閱讀試煉

《三國演義》逐回閱讀檢測網站，以 Google Apps Script 綁定 Google 試算表執行。

## 功能

- **逐回閱讀**：每回附原文，可切換直排／橫排；詩詞與表文另以版面區隔。
- **閱讀設定**：字型（明體、楷體、標楷體、黑體）、字級（小／中／大／特大或 14～30px 滑桿）、行距，記在裝置上下次自動套用。
- **難字注音與詞語小註**：原文中標有虛線的詞語點一下即顯示注音與解釋（「註釋」工作表，第 1～5 回共 230 條）。
- **專名號**：人名、地名、朝代、年號加直線，書名加波浪線（直排時畫在字的左側）；主要地名點一下顯示今地。可在「字型・字級」關閉（「專名」工作表）。
- **選字查詢與提問**：在原文選取任何詞語，可直接查教育部《重編國語辭典修訂本》，登入的學生還能按「看不懂，告訴老師」；教師後台「學生提問詞語」彙整人數，按「加註」即新增註釋。
- **人物小卡**：點人名顯示字號、陣營、簡介與「到目前為止」的事蹟，只列已讀回數，不劇透（「人物」「人物事蹟」工作表）。
- **錯題本與錯題重練**：收錄答錯的題目，可逐題訂正、回原文對照；「錯題重練」隨機抽 10 題、打亂選項重考，答對自動訂正（訂正紀錄存於「錯題訂正」工作表，換裝置也在）。
- **人物關係圖**：依已讀回數解鎖人物與關係，可切換「顯示到第幾回」看關係如何演變，點人物看小卡（「人物關係」工作表）。
- **地圖與時間軸**：每回事件標在漢末示意地圖上，點回目顯示該回路線，可放大洛陽周邊（「地點事件」工作表）。
- **班級挑戰與排行榜**：學生首頁顯示全班完成率目標進度與班內排行（姓名可遮蔽），可在「設定」關閉。
- **公告與必讀**：教師後台發布公告、指定必讀回次與截止日，可針對班級；學生首頁置頂顯示，回目卡標「必讀」，後台看完成人數。
- **閱讀進度與成就印章**：目錄上方顯示進度與八枚成就印章。
- **回末小結卡**：交卷後顯示本回大事、名句與想一想，可下載成圖片（「回末小結」工作表）。
- **書籤**：在讀到的段落夾書籤、跳回、刪除；登入者書籤跟著帳號走，並自動記住上次閱讀位置。
- **戰況面板（隨閱讀變化）**：閱讀區上方為 16-bit 風格對陣畫面：SNES 式藍底視窗、九種像素場景（戰場、黃昏、夜、桃園、水戰、攻城、火攻、宮廷、營帳；火與水會動）、32×32 像素人物（含騎馬、待機／出招／受創動作）、後方依形勢排列的軍陣、分段血條、說明列人物頭像、戰鼓音效、像素字型「俐方體11號」。畫面**只依目前讀到的原文位置**變化，與作答無關，不會出現「玩家操作改寫史實」的誤解；原文有寫兵力才標數字，勢只分「佔優／相持／潰敗」，一律標「依文意示意」。面板高度固定，切換畫面時原文不會跟著跳動；可收合成一行。
- **戰況時間軸**：面板下方一排色條代表本回各幕（紅＝軍陣、橙＝單挑、紫＝謀略、綠＝平時；黃邊＝有預測；綠底＝已找到依據），點一下跳到該幕的原文位置。
- **找依據**：在戰況面板按「找依據」，到原文點出支持這個畫面的句子；點錯會提示「再往前／往後」「在更前面的段落」，錯兩次可要提示。找到的幕會記在存檔、時間軸與圖鑑。
- **預測（不計分）**：讀到關鍵處（例如義軍五百對黃巾五萬）跳出小問題，先猜接下來怎麼發展；讀到下一幕時提醒「你剛才預測……對照原文看看」。
- **圖鑑與戰報卡**：首頁「圖鑑」：人物依讀到的段落解鎖（頭像與造型取自「人物造型」表），戰役依讀到的幕解鎖並標出已找到依據者；「戰報卡」可下載本回戰役與雙方形勢的圖片。交卷後的結算頁也有「本回戰報卡」。
- **勢力版圖**：「人物・地圖」的地圖依「地點事件」表的勢力欄著色並附圖例，隨「顯示到第幾回」改變。
- **閱讀進度條**：閱讀時頂欄下緣顯示本回已讀比例；學生讀到的最遠段落存在帳號裡（圖鑑解鎖依此）。
- **版面自由選搭**：閱讀頁上方「顯示」可分別開關「原文」「戰況畫面」「閱讀檢測」，七種組合皆可（至少留一項）；「版面▾」提供一鍵切換：專心閱讀、圖文對照、邊讀邊答、全部顯示、只看戰況。設定記在這台裝置。只開戰況畫面時，改以「◀ 上一幕／下一幕 ▶」逐幕瀏覽，並附原文依據句。手機上原文與檢測同開時以分頁切換。
- **造型與勢力資料表**：人物外觀（頭飾、鬍鬚、武器、配色、坐騎）在「人物造型」表、勢力配色在「勢力」表，新增人物或勢力只要填表，不必改程式。
- **內容包與審核上架**：一回的全部內容寫成一份 JSON「內容包」（格式見 `docs/內容包格式.md`，範例 `packs/第一回.json`），用試算表選單「匯入內容包」貼上，系統先檢查（錨句是否在原文、兵力數字是否出自原文、題目欄位、簡體字……），沒有錯誤才寫入，並設為「待審」；教師在後台「內容審核」預覽、檢查後按「上架」，學生才看得到。
- **作答**：題庫第一回 20 題，每次分層隨機抽 10 題（「設定 → 每次抽題數」），題序與選項排列打亂，抽到的題組由伺服器記在存檔裡，重新整理不會重抽，正解作答後才由伺服器回報；答題與戰況分開，對錯只計成績。題庫「人物」欄（選填）填人物小卡的姓名即可。
- **展示模式**：登入頁「▶ 展示模式」由電腦自動示範（免登入、不記錄成績）：自動捲動第一回原文、戰況面板隨之變化（含往回捲倒退）、自動作答十題、顯示結算，並有亮點字幕與虛擬游標；結束可重播。
- **每回題庫**（教師可在後台「題庫管理」新增、修改、刪除）：題型為文意理解、人物、概念（舊的劇情、意象、修辭仍可用）；解析可跳回原文對應段落。
- **AI 插圖**：每回最精彩處附插圖（Gemini 生成）。第一回為三格漫畫版，對話氣泡以網頁文字疊在圖上，台詞取自原文，可在「插圖」工作表「對話氣泡」欄修改（格式：`類型|說話者|x%|y%|寬%|尾端x%|尾端y%|台詞`，類型為說／想／吼／白，一行一個）。
- **古琴音樂與音效**：瀏覽器即時合成，無外部音檔。右上角「琴音」鈕開關；記得上次狀態，下次第一次點擊頁面時接續播放（直接點琴音鈕不會被重複切換）。
- **學生存檔**：作答自動存檔，記錄閱讀位置；可設定是否允許重作（記首次、最高、最近得分）。
- **登入**：名單內學生用帳號密碼登入（首次登入以姓名驗證後自設密碼），名單外讀者可自行註冊。
- **免登入試閱**：登入頁最上方即可免註冊、免登入閱讀並作答指定回數（預設第一回，於「設定 → 訪客試讀回數」調整）；訪客成績不記錄，答案只暫存在該裝置。
- **製作與版權說明頁**：頂欄「說明」按鈕；製作者、聯絡方式、授權聲明可在「設定」工作表修改。
- **教師後台**：依班級檢視成績總表、各題答對率與選項分布、「最需要講解的段落」排序、每位學生各回的開始時間、交卷時間與累計閱讀作答用時（閒置超過 2 分鐘不計），可下載 Excel（班級總表、作答明細、各題答對率）。

## 部署

1. 新增 Google 試算表 →「擴充功能 → Apps Script」。
2. 依上表建立 `.gs` 與 `.html` 檔並貼上內容（HTML 檔名不要打 `.html`）。
3. 在編輯器執行 `setupSheets` 並授權，會建立所有工作表（設定、學生名單、原文、題庫、插圖、存檔、作答紀錄、註釋、人物、人物事蹟、回末小結、人物關係、地點事件、公告、錯題訂正、專名、詞語提問、戰況、人物造型、勢力、回目狀態）。
   已部署過舊版者：更新程式後執行 `setupSheets`（補建新工作表與新欄位），再執行 `applyChapter1Upgrade`（第一回戰況新欄位、人物造型、勢力、地點勢力）。
4. 在「學生名單」填入學生，在「設定」修改「教師密碼」（預設 `nanshan`）。
5. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分「我」，存取權依需要選擇。之後更新請用「管理部署作業 → 編輯 → 建立新版本」，網址不變。

增加回數：用 `tools/epub_extract.py` 產生原文骨架，填好內容後 `node tools/check_pack.js` 檢查，再以試算表選單「匯入內容包」匯入，到教師後台「內容審核」上架。
